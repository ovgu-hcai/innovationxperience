# Innovation Xperience

A dark, interactive, glassmorphic redesign built with React, Vite and Framer Motion.

## Development

Run `npm install`, then `npm run dev`. Build for production with `npm run build`.

The Vite base is relative, so the generated site works on GitHub Pages project URLs.

## Editing website content

All visible text, navigation labels, events, team profiles, links, research topics,
contact details and sponsor metadata live in `src/siteContent.js`. Edit that one file
to update content without touching the React layout or animation code.
